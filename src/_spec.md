# 題庫寫作規範（經濟學通關 · econ-rogue）

> 給寫題 agent 看的。讀完就照著寫，不要改格式。

## 一、這是什麼

一個答題肉鴿網頁遊戲。玩家每關抽 6 題、靠答對拿分、道具放大分數。
你負責寫其中幾關的題庫。

**全部用繁體中文**（香港／台灣教材用語）：市場、邊際、盈餘、淨損失、競爭、賣家、買家、價格、供應、需求。
不要寫簡體，不要混英文句子（術語可括號註明英文）。

## 二、輸出格式

每關一個 JSON 陣列，寫到指定文件。UTF-8、無 BOM、可以被 `json.load` 讀取。

```json
[
  {
    "id": "1-1-01",
    "ch": 1,
    "level": "1-1",
    "tag": "市場定義",
    "diff": 2,
    "q": "題幹（20–60 字）",
    "opts": ["選項A", "選項B", "選項C", "選項D"],
    "ans": 1,
    "exp": "解析：為什麼對，關鍵陷阱在哪，其他選項錯在哪（60–160 字）",
    "src": "課堂筆記 Ch12"
  }
]
```

欄位規則：

| 欄位 | 規則 |
|---|---|
| `id` | `<level>-NN`，NN 從 01 起遞增，同一文件內不得重複 |
| `ch` | 整數，跟 `level` 前半一致（1 或 2） |
| `level` | 字串，等於指定關卡 id，例如 `"1-2"` |
| `tag` | 2–6 字知識點標籤，例如「市場結構」「寡頭」「消費者盈餘」「邊際成本」 |
| `diff` | 2、3、4 三檔（2 基礎記憶、3 理解比較、4 情境應用／計算） |
| `q` | 繁體，可含英文術語，不要出現「以上皆是」「下列何者錯誤」以外的套話 |
| `opts` | **剛好 4 個**字串，彼此互斥、長度接近；不要「以上皆是 / 以上皆非」 |
| `ans` | 正確選項下標 0–3 |
| `exp` | 解析，必須說明陷阱，不要只重複正確答案 |
| `src` | `課堂筆記 Ch12` 或 `課堂筆記 Ch13` |

**硬性要求**
1. 每題 4 個選項、`ans` 在 0–3。
2. 每關 `ans` 要分散：0/1/2/3 各約 1/4，不要把答案全放 B。
3. 同一關內不得有重複或近義重複的題幹。
4. 難度分佈：每關 16 題 → diff 2 佔 5–6 題、diff 3 佔 7–8 題、diff 4 佔 3–4 題。
5. 題型要有變化：定義判斷、特徵配對、情境應用、簡單計算、比較排序。
6. 只考筆記有的知識點（見 `structure.json` 的概念卡），可以用標準經濟學推論補強，但不要引入沒教過的公式（例如彈性公式不必）。

## 三、關卡與考點

先讀 `econ-rogue/src/structure.json`，每關有 `card`（概念卡）和 `trap`（陷阱）。
**題目要覆蓋該關全部概念卡條目，並至少有一題直接針對 `trap` 設計。**

### 第 1 章　市場與市場結構（筆記 Ch12）

- `1-1` 市場的定義與功能：市場不需實體地點；買賣雙方為商品和服務交易而接觸；市場分類依據
- `1-2` 市場結構的分類：市場結構的定義；完全競爭 vs 不完全競爭；不完全競爭三分（壟斷性競爭／寡頭壟斷／壟斷）；分類維度
- `1-3` 四種市場結構的特徵：賣家數目、商品性質（同質／異質）、進入容易度、市場資訊、價格與非價格競爭、市場影響力、競爭程度排序
- `1-4` 競爭行為與市場影響力：價格競爭 vs 非價格競爭；誰是定價者 price maker、誰是受價者 price taker；壟斷→寡頭→壟斷性競爭→完全競爭的競爭程度排序

### 第 2 章　效率、公平與政府的角色（筆記 Ch13）

- `2-1` 總利益與邊際利益：總利益定義；邊際利益定義；邊際利益＝願付最高價；邊際利益＝需求曲線；買到「價格＝邊際利益」為止
- `2-2` 消費者盈餘：定義＝願付最大數額 − 實際支付；圖形面積；價格下跌的影響；完全差別取價吃掉盈餘
- `2-3` 成本、邊際成本與生產者盈餘：總成本＝固定成本＋可變成本；邊際成本＝多生產一單位的成本＝最低願收價；邊際成本＝供應曲線；生產到「價格＝邊際成本」；生產者盈餘定義
- `2-4` 效率與淨損失：效率條件（價格＝邊際利益＝邊際成本）；總社會盈餘最大；缺乏效率（市價高於均衡價）→ 淨損失；淨損失由誰承擔（雙方合計變少，不是單方）

**第 2 章要多出計算題**，例如：
- 願付 50 元、實付 30 元 → 消費者盈餘 20 元
- 生產者最低願收 20 元、實收 35 元 → 生產者盈餘 15 元
- 總成本 = 固定成本 120 + 可變成本 80 = 200
- 市價高於均衡價 → 交易量減少 → 淨損失出現（判斷題）
- 總社會盈餘 = 消費者盈餘 + 生產者盈餘

**第 1 章多出比較題與情境題**，例如：
- 「街市裡有幾十檔賣同款青菜，菜式完全一樣」→ 完全競爭
- 「一個城市只有一間自來水公司」→ 壟斷
- 「幾間大電訊商搶客，各出月費優惠」→ 寡頭壟斷
- 「餐廳靠裝修、服務、品牌區分，彼此不是完全一樣」→ 壟斷性競爭

## 四、自檢（寫完必須跑）

用 DSH 自帶 python（系統 python 是商店佔位，不能用）：

```powershell
$py = "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py -c "import json;d=json.load(open(r'你的文件路徑',encoding='utf-8'));print('count',len(d));assert all(len(x['opts'])==4 for x in d);assert all(0<=x['ans']<=3 for x in d);ids=[x['id'] for x in d];assert len(ids)==len(set(ids));print('ans dist',{i:sum(1 for x in d if x['ans']==i) for i in range(4)})"
```

`count` 要等於指定題量，`ans dist` 四個數字要大致平均。
有任何失敗就自己修到通過，再回報。
